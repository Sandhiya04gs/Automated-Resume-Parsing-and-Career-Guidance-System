# Automated Resume Parsing and Career Guidance System

## 📌 Project Overview

The Automated Resume Parsing and Career Guidance System is a Python-based web application designed to help students, fresh graduates, and job seekers analyze their resumes and improve their career readiness.

The system extracts relevant information from uploaded resumes, analyzes user skills, and provides career recommendations and certification suggestions based on the analyzed profile.

## 🎯 Objectives

- Automate resume information extraction.
- Analyze candidate skills and qualifications.
- Evaluate resume content.
- Provide relevant career recommendations.
- Suggest certifications and skill improvements.

## ✨ Key Features

- Resume Upload and Parsing
- Resume Information Extraction
- Skill Identification and Analysis
- Automated Resume Scoring
- Career Recommendations
- Certification Suggestions
- Resume Improvement Suggestions

## 🛠️ Technologies Used

**Programming Language:** Python

**Backend:** Flask

**Frontend:** HTML, CSS, JavaScript, Bootstrap

**Database:** SQLite

**Libraries:** SQLAlchemy, PyPDF2, python-docx

## ⚙️ Application Workflow

1. User uploads a resume.
2. The system extracts resume information.
3. Extracted information and skills are analyzed.
4. The system evaluates the resume using predefined keywords.
5. Career recommendations and certification suggestions are provided.
6. Users receive suggestions to improve their resumes and skills.

## 👥 Target Users

- Students
- Fresh Graduates
- Job Seekers
